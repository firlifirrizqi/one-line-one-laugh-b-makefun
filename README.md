A single original funny line (95 characters) for the Make.fun
"One Line, One Laugh" competition. `main.py` (stdlib only) writes the
line to `/output/entry.txt` and verifies the 1–200 character gate plus a
byte-identical read-back.

Line: "My password manager forgot my password. Now we stare at each other like strangers at a reunion."
